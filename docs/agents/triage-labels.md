# 问题分类标签

工程技能通过五个标准角色描述工单状态；执行时使用下表映射到实际 GitHub 标签，不因中文说明而另建同义标签。

| 技能中的标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者判断范围、价值与下一步 |
| `needs-info` | `needs-info` | 信息不足，等待报告者补充 |
| `ready-for-agent` | `ready-for-agent` | 需求及验收明确，可由自主 Agent 实施 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或人工实施 |
| `wontfix` | `wontfix` | 已决定不处理 |

技能提到这些角色时，使用“本仓库标签”列。以后要使用既有自定义标签，直接修改这一列，并确保 GitHub 中存在对应标签。
